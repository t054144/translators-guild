# Lineage images

One image per figure. The site loads these by filename; nothing is fetched
from any outside site at runtime.

Save each file here with **exactly** the filename below. Keep the extension
as listed. A square-ish original crops best, but the card crops to 1:1.

Until a file exists the card shows an empty frame. It never shows initials,
never substitutes another image, and never generates a face.

What each image honestly is — manuscript, later depiction, imagined
depiction, painted depiction, engraving, or a real photograph — is recorded
against it in `FIGURE_IMAGE` in index.html, with its source and credit. The
alt text is written from that record, so a depiction is never described as
a portrait, and no caption names a painter who has not been confirmed.
