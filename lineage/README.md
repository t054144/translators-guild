# Lineage images

One image per figure. The site loads these by filename; nothing is fetched
from any outside site at runtime.

Save each file here with **exactly** the filename in the table. Any format
works if you keep the extension in the name (.jpg or .png as listed).
A square-ish original crops best, but the card crops to 1:1 itself.

| File | Who | What the image is |

| `william-tyndale.jpg` | William Tyndale | Historical portrait, Pitts Theology Library |
| `gregory-rabassa.jpg` | Gregory Rabassa | Photograph, New Directions Publishing |

Until a file exists the card shows an empty frame. It never shows initials,
never substitutes another image, and never generates a face.

What each image honestly is — manuscript, later depiction, imagined
depiction, or a real photograph — is recorded against it in the page, in
`FIGURE_IMAGE`, along with its source and credit. That record is what the
alt text is written from, so a depiction is never described as a portrait.
