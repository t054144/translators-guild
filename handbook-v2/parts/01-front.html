How to use this handbook

كيف تستخدم هذا الدليل

This handbook is for beginners. It explains the basics of translating between English and Arabic, one step at a time.

The order of the book

The chapters follow the order in which a translator actually works:

Part 5 introduces useful tools and text types. Part 6 gives you exercises, with answers.

How each chapter works

Every chapter has the same simple layout, so you always know where to look:

  1. Introduction: what you will learn.
  2. Key terms: the main words, with their Arabic equivalents.
  3. Explanation: short sections with examples.
  4. Remember: the most important points.

Signs used in this book

EN → AREnglish source text, Arabic translation
AR → ENArabic source text, English translation
✓ and ✗A good translation and a poor translation
SL / TLSource language / target language (اللغة المصدر / اللغة الهدف)
ST / TTSource text / target text (النص المصدر / النص الهدف)
