How it will work

  • You enter the reference from your request
  • We send a one-time code to the contact you gave us
  • The code — not the reference alone — opens the request
  • You see its stage, and nothing about anyone else’s

A reference number alone will never be enough to open a request. That is deliberate: anyone can guess at a number, and a request holds a name and a way to contact someone.
