# r/SpaceX API v4 — reassembled from community mirrors

The origin (`api.spacexdata.com/v4`) was archived on 6 June 2026 and no longer
answers. These files are verbatim dumps of its collections, taken from public
GitHub repositories that had saved them while the API was live. Every foreign
key between collections resolves (checked at ingest), which is what confirms
they came from the same era of the same database.

The dataset is frozen: last launch 2022-12-05. Nothing after that exists here.
